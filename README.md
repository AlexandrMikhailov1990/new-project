# Тренажёр — дневник тренировок

Веб-приложение для зала: программы, запись подходов, таймер работы/отдыха и статистика прогресса. Интерфейс на русском. Данные хранятся локально в браузере (`localStorage`), без бэкенда.

## Возможности

- Готовые программы: **Фулбади**, **Жим / Тяга / Ноги**, **Верх / Низ** — можно править и добавлять свои
- В сессии: выбор упражнений, повторы, вес, время работы и отдыха
- Простой таймер работы и отдыха (с вибрацией на поддерживаемых устройствах)
- История тренировок, объём по неделям, личные рекорды
- Во время упражнения — прошлые подходы и лучшие результаты

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Сборка:

```bash
npm run build
npm run preview
```

## Стек

Vite · React · TypeScript · React Router · CSS (без UI-kit)

## Структура данных

Локальное хранилище ключ `trenazher-app-v1`: программы, каталог упражнений и сессии. Архитектура local-first — позже можно подключить API, не меняя модель.
