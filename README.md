# Тренажёр — дневник тренировок

Веб-приложение для зала: программы, запись подходов, таймер работы/отдыха и статистика прогресса. Интерфейс на русском. Данные хранятся локально в браузере (`localStorage`), без бэкенда.

## Возможности

- Готовые программы: **Фулбади**, **Жим / Тяга / Ноги**, **Верх / Низ** — можно править и добавлять свои
- В сессии: упражнения, подходы (повторы, вес, время работы и отдыха)
- Таймер работы/отдыха под телефон (крупные кнопки, экран не гаснет на время таймера, где поддерживается)
- История тренировок, объём по неделям, личные рекорды
- Во время упражнения — прошлые подходы и лучшие результаты

## Запуск на компьютере

```bash
npm install
npm run dev
```

Vite слушает **все сетевые интерфейсы** (`--host`), обычно порт `5173`. В терминале появятся адреса:

- Local: `http://localhost:5173/`
- Network: `http://192.168.x.x:5173/` ← этот нужен для телефона

Сборка:

```bash
npm run build
npm run preview
```

`preview` тоже с `--host` (порт `4173`).

## Открыть на телефоне (тот же Wi‑Fi)

1. Компьютер и телефон в **одной Wi‑Fi сети**.
2. На компьютере: `npm run dev` (или `npm run preview` после сборки).
3. Узнайте IP компьютера из строки **Network** в выводе Vite  
   или вручную:
   - macOS/Linux: `ipconfig getifaddr en0` / `hostname -I`
   - Windows: `ipconfig` → IPv4-адрес
4. В браузере телефона откройте: `http://<IP>:5173`  
   пример: `http://192.168.1.42:5173`
5. Если страница не открывается — проверьте файрвол (разрешить входящие на порт 5173/4173) и что это домашняя/частная сеть, а не гостевой Wi‑Fi с изоляцией клиентов.

### На домашний экран (удобно в зале)

В Safari/Chrome на телефоне: «Поделиться» → **На экран «Домой»** / **Установить приложение**.  
Есть `manifest.webmanifest` для standalone-режима (без service worker — это не полноценный offline-PWA).

### Если нужна ссылка из другой сети

Практичный вариант без настройки роутера — временный туннель с машины, где крутится Vite, например:

```bash
npx --yes localtunnel --port 5173
# или: npx --yes cloudflared tunnel --url http://localhost:5173
```

Откройте выданную HTTPS-ссылку на телефоне. Не оставляйте туннель открытым без нужды.
