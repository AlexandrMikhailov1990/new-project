# Тренажёр — дневник тренировок

Веб-приложение для зала: программы, подходы, таймер и статистика. UI на русском. Данные в `localStorage` на телефоне — компьютер в зале не нужен.

## С телефона далеко от компьютера (без общей Wi‑Fi)

Нужен **публичный HTTPS-сайт** + установка на домашний экран. После первого открытия приложение кэшируется и работает **офлайн**.

### Постоянный доступ (рекомендуется) — GitHub Pages

Репозиторий сейчас **private**, а готовая сборка уже в ветке `gh-pages`. Один раз:

1. GitHub → **Settings → General → Danger Zone → Change visibility → Public**  
   *(на бесплатном плане Pages для private обычно недоступны)*
2. **Settings → Pages** → Source: **Deploy from a branch** → Branch **`gh-pages`** / root → Save
3. Откройте на телефоне: **https://alexandrmikhailov1990.github.io/new-project/**
4. Chrome/Safari → «На экран Домой» / «Установить приложение»
5. В зале запускайте с иконки — сеть не обязательна

Обновить сайт после правок:

```bash
npm install
npm run deploy:pages
```

### Альтернатива: свой хостинг (Vercel / Netlify)

```bash
npm run build
npx vercel deploy --yes          # или: npx netlify deploy --dir=dist --prod
```

Закрепите URL в закладках / на домашнем экране телефона.

## Возможности

- Программы: Фулбади, Жим/Тяга/Ноги, Верх/Низ (редактируемые)
- Подходы: повторы, вес, работа/отдых + таймер
- Offline PWA (service worker + локальные шрифты)
- История, объём, рекорды, прошлые результаты в сессии

## Разработка на компьютере

```bash
npm install
npm run dev          # --host, обычно :5173
npm run build && npm run preview
```

Та же Wi‑Fi: адрес **Network** из вывода Vite (для отладки, не для зала вдали от ПК).

## Данные

Ключ `trenazher-app-v1` в `localStorage` **этого** телефона/браузера. Синхронизации между устройствами пока нет.
