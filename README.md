# Тренажёр — дневник тренировок

Веб-приложение для зала: программы, запись подходов, таймер работы/отдыха и статистика прогресса. Интерфейс на русском. Данные в `localStorage` на телефоне — бэкенд не нужен.

## С телефона без компьютера и без общей Wi‑Fi

После деплоя на GitHub Pages приложение доступно по публичной HTTPS-ссылке с мобильного интернета (или любой сети):

**https://alexandrmikhailov1990.github.io/new-project/**

1. Откройте ссылку в Chrome/Safari на телефоне.
2. Один раз дождитесь загрузки (установится offline-кэш / PWA).
3. «Поделиться» → **На экран «Домой»** / **Установить приложение**.
4. В зале открывайте иконку с домашнего экрана — работает **офлайн**, компьютер не нужен. Прогресс остаётся в памяти браузера телефона.

Если Pages ещё не включены в репозитории: Settings → Pages → Source **GitHub Actions**, затем дождитесь workflow **Deploy to GitHub Pages** (пушится с `main` и с ветки приложения).

Сборка под Pages локально:

```bash
npm install
npm run build:pages
```

## Возможности

- Программы: **Фулбади**, **Жим / Тяга / Ноги**, **Верх / Низ** (редактируемые)
- Подходы: повторы, вес, время работы и отдыха + таймер
- Offline PWA: после первого визита — без сети
- История, объём, личные рекорды и прошлые результаты в сессии

## Разработка на компьютере

```bash
npm install
npm run dev
```

Vite с `--host` (LAN). Local: `http://localhost:5173/`  
На телефоне в **той же Wi‑Fi**: адрес **Network** из терминала, например `http://192.168.1.42:5173`.

```bash
npm run build
npm run preview
```

## Стек

Vite · React · TypeScript · React Router (Hash) · vite-plugin-pwa · localStorage

## Данные

Ключ `trenazher-app-v1` в `localStorage` браузера устройства. На каждом телефоне — своя копия (sync между устройствами пока нет).
